## Objective and Purpose

The **Title Claim Tracker** centralizes the tracking of legal filings — specifically title claims, liens, and easements — associated with real estate properties. The system provides an efficient dashboard for tracking filing statuses, supports full CRUD operations on property and filing records, and enforces strict business rules through a clean 3-tier architecture.

The application serves as a showcase of professional-grade C# engineering: LINQ-driven data access, T-SQL stored procedures and triggers, Entity Framework ORM, AJAX-powered asynchronous UX, and a comprehensive testing strategy across unit, integration, and end-to-end layers.

## System Architecture

### 3-Tier Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                 PRESENTATION LAYER (Tier 1)                     │
│                                                                 │
│  Razor Views (.cshtml)  │  JavaScript + jQuery  │  AJAX Calls  │
│  HTML Forms             │  Client Validation    │  Async UX    │
└───────────────────────────────┬─────────────────────────────────┘
                                │ HTTP Requests (GET / POST)
                                ┌───────────────────────────────▼─────────────────────────────────┐
                                │                APPLICATION LAYER (Tier 2)                       │
                                │                                                                 │
                                │  ASP.NET MVC Controllers   │  Service Layer (FilingService.cs)  │
                                │  Business Logic (C#)       │  LINQ Data Access                 │
                                │  Status Transition Rules   │  DTOs (FilingSummaryDTO)          │
                                │  Validation + Error Handle │  Dependency Injection             │
                                └───────────────────────────────┬─────────────────────────────────┘
                                                                │ Entity Framework / ADO.NET
                                                                ┌───────────────────────────────▼─────────────────────────────────┐
                                                                │                    DATA LAYER (Tier 3)                          │
                                                                │                                                                 │
                                                                │  SQL Server Database       │  Stored Procedures                │
                                                                │  Normalized Schema (3NF)   │  Audit Triggers (T-SQL)           │
                                                                │  Entity Framework Context  │  Indexes + Query Optimization     │
                                                                └─────────────────────────────────────────────────────────────────┘
                                                                ```

                                                                ### MVC Request Flow

                                                                ```

                                                                                                                                                                  ## Layer-by-Layer Technical Detail
                                                                                                                                                                  
                                                                                                                                                                  ### Tier 1 — Presentation Layer (Frontend)
                                                                                                                                                                  
                                                                                                                                                                  The presentation layer manages all user interaction through Razor Views and client-side logic.
                                                                                                                                                                  
                                                                                                                                                                  **Razor Views** mix HTML with C# code to dynamically generate content from the ViewModel provided by the controller:
                                                                                                                                                                  
                                                                                                                                                                  ```cshtml
                                                                                                                                                                  @model IEnumerable<FilingSummaryDTO>
                                                                                                                                                                  @foreach (var filing in Model)
                                                                                                                                                                  {
                                                                                                                                                                      <tr>
                                                                                                                                                                              <td>@filing.FilingID</td>
                                                                                                                                                                                      <td>@filing.PropertyAddress</td>
                                                                                                                                                                                              <td>@filing.Status</td>
                                                                                                                                                                                                      <td>
                                                                                                                                                                                                                  <button class="btn-quick-status" data-id="@filing.FilingID">
                                                                                                                                                                                                                                  Quick Update
                                                                                                                                                                                                                                              </button>
                                                                                                                                                                                                                                                      </td>
                                                                                                                                                                                                                                                          </tr>
                                                                                                                                                                                                                                                          }
                                                                                                                                                                                                                                                          ```
                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                          **AJAX Quick Status Update** — The status update runs asynchronously without a full page reload:
                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                          ```javascript
                                                                                                                                                                                                                                                          $('.btn-quick-status').on('click', function () {
                                                                                                                                                                                                                                                              const filingId = $(this).data('id');
                                                                                                                                                                                                                                                                  const newStatus = $('#status-select-' + filingId).val();
                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                      $.ajax({
                                                                                                                                                                                                                                                                              url: '/Filing/QuickStatusUpdate',
                                                                                                                                                                                                                                                                                      type: 'POST',
                                                                                                                                                                                                                                                                                              data: { filingId: filingId, newStatus: newStatus },
                                                                                                                                                                                                                                                                                                      success: function (result) {
                                                                                                                                                                                                                                                                                                                  $('#status-badge-' + filingId).text(newStatus).addClass('updated');
                                                                                                                                                                                                                                                                                                                          },
                                                                                                                                                                                                                                                                                                                                  error: function () {
                                                                                                                                                                                                                                                                                                                                              alert('Status update failed. Please try again.');
                                                                                                                                                                                                                                                                                                                                                      }
                                                                                                                                                                                                                                                                                                                                                          });
                                                                                                                                                                                                                                                                                                                                                          });

                                                                                                                                                                                                                                                                                                                                                          ### Tier 2 — Application Layer (Backend)
                                                                                                                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                                                                          The application layer enforces all business rules and orchestrates data flow between presentation and data layers.
                                                                                                                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                                                                          **Controller — Routes and Orchestrates:**
                                                                                                                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                                                                          ```csharp
                                                                                                                                                                                                                                                                                                                                                          [HttpPost]
                                                                                                                                                                                                                                                                                                                                                          [ValidateAntiForgeryToken]
                                                                                                                                                                                                                                                                                                                                                          public async Task<IActionResult> Create(FilingCreateViewModel model)
                                                                                                                                                                                                                                                                                                                                                          {
                                                                                                                                                                                                                                                                                                                                                              if (!ModelState.IsValid)
                                                                                                                                                                                                                                                                                                                                                                      return View(model);
                                                                                                                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                                                                          try
                                                                                                                                                                                                                                                                                                                                                                              {
                                                                                                                                                                                                                                                                                                                                                                                      await _filingService.CreateFilingAsync(model);
                                                                                                                                                                                                                                                                                                                                                                                              TempData["Success"] = "Filing created successfully.";
                                                                                                                                                                                                                                                                                                                                                                                                      return RedirectToAction(nameof(Index));
                                                                                                                                                                                                                                                                                                                                                                                                          }
                                                                                                                                                                                                                                                                                                                                                                                                              catch (InvalidOperationException ex)
                                                                                                                                                                                                                                                                                                                                                                                                                  {
                                                                                                                                                                                                                                                                                                                                                                                                                          TempData["Error"] = ex.Message;
                                                                                                                                                                                                                                                                                                                                                                                                                                  return View(model);
                                                                                                                                                                                                                                                                                                                                                                                                                                      }
                                                                                                                                                                                                                                                                                                                                                                                                                                      }
                                                                                                                                                                                                                                                                                                                                                                                                                                      ```
                                                                                                                                                                                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                                                                                                                                      **Service Layer — Enforces Business Rules:**
                                                                                                                                                                                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                                                                                                                                      ```csharp
                                                                                                                                                                                                                                                                                                                                                                                                                                      // FilingService.cs — Status transition enforcement
                                                                                                                                                                                                                                                                                                                                                                                                                                      public async Task UpdateStatusAsync(int filingId, string newStatus)
                                                                                                                                                                                                                                                                                                                                                                                                                                      {
                                                                                                                                                                                                                                                                                                                                                                                                                                          var filing = await _context.LegalFilings.FindAsync(filingId);
                                                                                                                                                                                                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                                                                                                                                                              if (filing == null)
                                                                                                                                                                                                                                                                                                                                                                                                                                                      throw new InvalidOperationException("Filing not found.");
                                                                                                                                                                                                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                                                                                                                                                          // Business Rule: Prevent illogical status regressions
                                                                                                                                                                                                                                                                                                                                                                                                                                                              if (filing.Status == "Closed" && newStatus == "New")
                                                                                                                                                                                                                                                                                                                                                                                                                                                                      throw new InvalidOperationException(
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  "Cannot revert a Closed filing back to New status.");
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      filing.Status = newStatus;
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          await _context.SaveChangesAsync();
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          }
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          ```
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          **LINQ Data Access — Type-Safe, Injection-Free:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          ```csharp
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          // LINQ query via Entity Framework — replaces raw SQL strings
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          public async Task<List<FilingSummaryDTO>> GetFilingsByTypeAsync(int filingTypeId)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          {
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              return await _context.LegalFilings
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      .Where(f => f.FilingTypeID == filingTypeId)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              .Select(f => new FilingSummaryDTO
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      {
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  FilingID       = f.FilingID,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              PropertyAddress = f.Property.Address,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          FilingType     = f.FilingType.TypeName,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      Status         = f.Status,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  DateFiled      = f.DateFiled,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              ClaimantName   = f.ClaimantName
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      })
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              .OrderByDescending(f => f.DateFiled)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      .ToListAsync();
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      }
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      ```
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      ### Tier 3 — Data Layer (SQL Server)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      The data layer ensures integrity, performance, and a complete audit trail.
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      **Stored Procedure — Pre-compiled for Performance:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      ```sql
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      CREATE PROCEDURE sp_GetClaimsForReport
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          @FilingTypeID INT = NULL,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              @Status       NVARCHAR(50) = NULL
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              AS
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              BEGIN
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  SET NOCOUNT ON;
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      SELECT
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              f.FilingID,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      p.Address,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              p.City,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      p.State,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              ft.TypeName         AS FilingType,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      f.Status,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              f.DateFiled,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      f.ClaimantName,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              f.Notes
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  FROM LegalFilings f
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      INNER JOIN Properties p  ON f.PropertyID   = p.PropertyID
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          INNER JOIN FilingTypes ft ON f.FilingTypeID = ft.FilingTypeID
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              WHERE
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      (@FilingTypeID IS NULL OR f.FilingTypeID = @FilingTypeID)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              AND (@Status IS NULL OR f.Status = @Status)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  ORDER BY f.DateFiled DESC;
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  END;
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  ```
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  **Audit Trigger — Automatic Change Logging:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  ```sql

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  ON LegalFilings
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  AFTER UPDATE
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  AS
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  BEGIN
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      SET NOCOUNT ON;
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          INSERT INTO AuditLog (TableName, RecordID, ColumnChanged, OldValue, NewValue, ChangeDate)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              SELECT
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      'LegalFilings',
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              i.FilingID,
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      'Status',
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              d.Status,   -- Old value (from DELETED pseudo-table)

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  FROM INSERTED i

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          WHERE i.Status <> d.Status;  -- Only log when status actually changes
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          END;

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          ### Schema Design Principles
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          The schema follows **Boyce-Codd Normal Form (BCNF)** to eliminate data redundancy:
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          - Filing type names (`Lien`, `Easement`, `Title Claim`) are stored once in the `FilingTypes` lookup table — never duplicated in `LegalFilings`
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          - Property data is stored once in `Properties` and referenced by FK in every associated filing
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          - The `AuditLog` is append-only, written exclusively by the `trg_AuditLegalFilings` trigger — the application layer never writes to it directly
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          - All foreign key relationships are enforced at the database level, not just in application code

## Architecture
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 
 ```text
 Angular 17 browser application
         │ same-origin /api calls (Angular proxy for local development)
         ▼
 ASP.NET Core 8 controllers + services
         ├── ASP.NET Core Identity cookie authentication
         ├── server-side ownership and Admin authorization
         ├── EF Core 8 mappings and application audit writer
         └── ML.NET triage services (later workflow phases)
         ▼
 SQL Server database deployed by the reviewed 2.0.3 SSMS script
 ```
                                                                                                                                                                                                                                                                                                                                                                                                                                                                 
The property owner or claimant named in a filing is not the submitting account. `SubmittedByUserId` is the authenticated account owner used for authorization. The application does not make legal decisions, determine legal merit, or file documents with a court.

## Database contract and data safety

The database is script-managed. Follow [`TitleClaimTracker/Database/DatabaseSetup.md`](TitleClaimTracker/Database/DatabaseSetup.md) and run the complete [`Upgrade_TitleClaimIntelligence.sql`](TitleClaimTracker/Database/Upgrade_TitleClaimIntelligence.sql) only in the explicitly selected existing database, followed by [`Verify_TitleClaimIntelligence.sql`](TitleClaimTracker/Database/Verify_TitleClaimIntelligence.sql).

 - The current schema version is 2.0.3.
 - Do not run `Database.Migrate()`, `EnsureCreated()`, `dotnet ef database update`, the retired initializer, or root-level `TableCreation.sql`.
 - Do not use `USE`, `CREATE DATABASE`, SQLCMD variables, or `GO` in the standalone upgrade deployment.
 - The application never changes the schema at startup and no live database is used by automated tests.
 - Existing claims, category/status names and IDs, legacy statuses, audit dates, and Identity key constraints are preserved.
 - Claims are soft deleted and EF Core is the application audit writer; legacy audit triggers are not recreated.
 - Phase 1 requires no 2.0.4 schema change. A future schema need must be delivered as a separate reviewed script with matching EF mappings.

## Run locally

### Backend

From `TitleClaimTracker/`:

```powershell
dotnet restore
dotnet build
dotnet run
```

The development launch profile exposes `https://localhost:58011` and `http://localhost:58012`. Check `https://localhost:58011/health` after startup. Configure the actual SQL Server connection outside source control when it differs from `appsettings.json`:

```powershell
$env:ConnectionStrings__DefaultConnection = 'Server=localhost\SQLEXPRESS01;Database=TitleClaimTracker;Integrated Security=True;TrustServerCertificate=True;'
```

### Optional Admin bootstrap

The SQL script does not create users or passwords. Provision an administrator through ASP.NET Core Identity by setting external configuration only for the provisioning run, then disable it:

```powershell
$env:Identity__BootstrapAdmin__Enabled = 'true'
$env:Identity__BootstrapAdmin__Email = 'admin@example.test'
$env:Identity__BootstrapAdmin__Password = '<use-a-secret-password-manager-value>'
dotnet run
$env:Identity__BootstrapAdmin__Enabled = 'false'
```

Never put the bootstrap password in SQL, Angular code, Git, or a committed settings file.

### Angular client

From `TitleClaimTracker/ClientApp/`:

```powershell
npm ci
npm start
```

Open `http://localhost:4200`. The development proxy forwards `/api` and `/health` to the backend. The browser uses relative same-origin URLs, credentials, and Angular’s XSRF configuration. If a separate trusted frontend origin is used instead of the proxy, configure `Cors:AllowedOrigins` on the server; do not use wildcard origins with credentials.

## Authentication API

| Method | Endpoint | Purpose |
|---|---|---|
| `GET` | `/api/auth/csrf` | Issues the non-secret XSRF cookie used by unsafe requests. |
| `POST` | `/api/auth/register` | Creates a public `User` account and signs it in. |
| `POST` | `/api/auth/login` | Starts an authenticated Identity cookie session. |
| `POST` | `/api/auth/logout` | Ends the current session. |
| `GET` | `/api/auth/me` | Restores the current active account and roles. |

The cookie is `HttpOnly`, `SameSite=Lax`, and same-as-request secure; the XSRF token is deliberately readable by the Angular XSRF interceptor and is not an authentication credential. The server remains authoritative for roles and ownership.
